# Product

## Register

product

## Users

Players who want a fast, offline-capable browser game with keyboard or touch controls. They arrive expecting a playable game immediately, but with a title screen and hi score context before the first round starts.

## Product Purpose

Stackline is an original WASM-4 falling-block puzzle PWA. Success means the user can open it offline, see the title screen and hi score, start deliberately, play a compact classic-feeling round, and get persistent score feedback without any branded or copyrighted game assets.

## Brand Personality

Compact, precise, tactile.

## Anti-references

Avoid Nintendo/Game Boy/Tetris trade dress, official names, copied board chrome, Korobeiniki usage, fake emulator nostalgia clutter, and decorative marketing-page layouts.

## Design Principles

- Start with the game state: title, hi score, and start action are visible before play.
- Keep the shell quiet: the WASM-4 screen is the primary artifact.
- Use original handheld-inspired styling without imitating protected hardware or software branding.
- Make offline and update states explicit but unobtrusive.
- Prefer clear controls and readable score data over decorative copy.

## Accessibility & Inclusion

The PWA shell targets readable contrast, keyboard-first operation, touch support through the WASM-4 virtual gamepad when needed, and reduced-motion-safe UI transitions.
